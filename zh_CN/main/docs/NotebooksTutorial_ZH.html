Notebooks 教程#

欢迎来到 Data Juicer Hub 的 Notebooks 教程库！本分支包含了一系列 Jupyter notebooks，帮助你快速上手 Data Juicer。

🚀 快速开始#

除下述方法外，您也可以尝试 JupyterLab Playground with Tutorials。

方式一：Github Codespace#

  1. 启动 Codespace

    • 点击本仓库的 Code 按钮，选择 Codespaces 标签

    • 点击 Create codespace on notebook（+号） 启动环境

    • 稍等片刻，你将看到 VSCode Web 界面

  2. 选择并运行 Notebook

    • 在左侧文件目录中找到 notebooks 文件夹

    • 点击你感兴趣的 notebook 文件

    • 点击右上角的内核选择器，选择 data-juicer-hub 环境（位于 .venv 目录）

    • 开始运行！
